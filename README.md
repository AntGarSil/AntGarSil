## 🧠 How I approach security

> **Understand the system. Find the trust boundary. Break the assumptions. Reduce the risk.**

I prefer security controls that work *with* engineering rather than against it.

That usually means:

* automate repetitive security work;
* improve signal rather than generating more noise;
* put controls at the right boundary;
* make the secure path the easiest path;
* prioritise meaningful risk over theoretical perfection;
* and give engineers enough context to fix problems themselves.
